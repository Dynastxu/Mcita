## Development

### Environment Setup

1. Clone the project and its submodules to your local machine
2. Install Deepseek Harness or another Coding Agent
3. Deploy [mcp-neoforge-docs](https://github.com/Dynastxu/mcp-neoforge-docs) & [mcp-noita-data](https://github.com/Dynastxu/mcp-noita-data) and configure the MCP in the Coding Agent
